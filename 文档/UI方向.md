# UI 方向

- **Product**：在手机、平板和电视上浏览抖音短视频、直播及个人内容的第三方客户端
- **Character**：沉浸、直接、节奏快
- **World**：黑色放映空间，内容本身是主要光源
- **Moments**：全屏视频/直播画面；评论、合集与设置从边缘覆盖进入
- **Signature**：右侧纵向动作列 + 底部一条品牌红播放进度细线

## 规则

- 主色 `#FE2C55`，背景 `#0E0E0F`；白/灰三级文字，不做彩色渐变、发光或玻璃拟态
- 手机以纵向全屏 Pager、顶部频道、右侧动作列、底部导航为主
- 横屏/TV 保持全屏内容，导航和面板按遥控焦点临时出现；焦点边框明确但不过度放大
- 评论、相关视频、合集、直播选台、设置使用同一套边缘抽屉
- 所有间距按 4dp 网格；按钮 8–12dp 圆角，头像才使用圆形
- 动效只解释翻页、抽屉和按压；不做无意义循环动画
