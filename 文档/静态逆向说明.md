# 静态逆向说明

## 基线

- 官方项目：`mytv-android/myDV`
- APK：`V2.1.37`，versionCode 37，minSdk 23，targetSdk 37
- SHA-256：`7af8303338d94d7314981e5b347e8a2251741732162e7a335be3065d03387d45`
- 设备安装包、官方 Release 与本地反编译样本三者哈希一致

## 方法

1. Manifest / resources：apktool + JADX resources
2. DEX：JADX 1.5.7；R8 类名混淆后按字符串、模型、调用者和接口路径恢复职责
3. assets：直接从 APK ZIP 提取，逐文件 SHA-256 校验
4. 行为范围：导航枚举、偏好键与默认值、API 路径/参数、UI 文案、播放器与 PiP 调用链
5. 不运行、不查看本机原 App；动态联网只用于后续验证本项目，不用于猜界面

## 已确认组件

- 个人页 Tab：作品、喜欢、粉丝、关注、历史、收藏夹、稍后再看、合集

## 资产

APK 共 499 个 ZIP 条目、15 个 assets 文件。`取证资料/assets-sha256.txt` 是权威清单；实现会逐字节复制到 `app/src/main/assets`。新增的签名垫片和源码声明会单独标明，不伪装成原资产。
